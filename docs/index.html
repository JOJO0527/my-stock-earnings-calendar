    不需要时怎么清除

    1. 停止云端更新：打开上面的运行页面 → 右上角菜单 → Disable workflow。
    2. 移除日历：在苹果日历里取消订阅“自选股财报｜GitHub自动更新”；取消勾选只是隐藏。
    3. 彻底清除：先停用工作流，再到仓库 Settings → General → Danger Zone → Delete this repository。删除前核对仓库名称。

    停止任务后，已发布的文件可能仍可访问；删除仓库后订阅网址会失效。
